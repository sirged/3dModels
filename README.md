# 3D Models Repo

Source files for my personally created 3D models. Finished models end up on Thingiverse:
https://www.thingiverse.com/SirGed — anything still in beta/design stages lives only here.

Reorganised 2026-10-29 when moving from Fusion 360 to SolidCraft. See `E:\3D\README.md` for the
full map of where every old Fusion project and old repo folder went.

## Layout

One folder per category, then per project. Each design normally has three files side by side:

| File | Role |
|---|---|
| `Name.sc` | **SolidCraft design — the file to open and edit.** Converted from the STEP, so it has bodies, names and colours but not Fusion's timeline. |
| `Name.step` | Neutral exchange copy (AP242). |
| `Name.f3d` | Original Fusion 360 archive with full history. Reference only; needs Fusion to open. |
| `Name.stl` | Only for designs that were mesh imports in Fusion (no solids to put in a STEP). |

Printed exports (stl/3mf), renders (png) and notes from the old repo sit in the same project folders.

Folders starting with `_` are not "projects": `_vendor-parts` (downloaded reference parts: Bondtech,
E3D, BLTouch, aluminium extrusion…), `_scratch` (test files and one-offs), `_others` (Dan's shared hub).
